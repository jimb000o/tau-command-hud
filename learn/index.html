Cheat sheet
  • = equals, != not equal. There is no ==.
  • && and, || or, ! not, -> implies.
  • i1[t] input 1 at step t, o1[t] output 1, o1[t-1] the step before.
  • i1[t]:bv[8] an 8-bit number; { 5 }:bv[8] the constant 5. Bare digits are bits, not numbers.
  • always every step, sometimes at least once. No semicolons; the dot at the end is optional.
  • T and F are true and false. solve, normalize live in the tau REPL on your computer.

Looking for the engine…

Answers come from IDNI's tau-lang, built from source and newer than the 0.7 you can download, running on tauhud's server with a 5 second limit per question. Files, the console and network are switched off. Tau HUD is an unofficial community project, not affiliated with IDNI.

More

  1. 1
    Install tau. IDNI's only packaged release, v0.7-alpha from November 2024, has packages for Linux (.deb, .rpm) and an installer for Windows. The newer tau in IDNI's main README is only built from source.
    Download v0.7-alpha ↗Guide for 0.7 ↗
  2. 2
    Start it. Open a terminal and type tau. The REPL opens with a tau> prompt.
  3. 3
    Look around. help examples shows the syntax, help lists every command, q quits.
  4. 4
    Ask a first question. Type this at the prompt, with the dot at the end. Tau answers T: yes, x = 0 can be true. 
    sat x = 0.

The REPL runs only on your computer: no wallet, no server, no testnet. A line from these lessons may read differently in 0.7.
