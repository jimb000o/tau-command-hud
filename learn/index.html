Learn Tau Language

Learn Tau Language. No node needed.

Every rule on the Tau testnet is a Tau specification. To learn to write them you only need the tau program on your own computer: its REPL answers each line you type. A node is something else: it follows the chain and wants a server.

Start the REPL in four steps

  1. 1
    Install tau. IDNI's only packaged release, v0.7-alpha from November 2024, has packages for Linux (.deb, .rpm) and an installer for Windows. The newer tau in IDNI's main README is only built from source.
    Download v0.7-alpha ↗Guide for 0.7 ↗
  2. 2
    Start it. Open a terminal and type tau. The REPL opens with a tau> prompt.
  3. 3
    Look around. help examples shows the syntax, help lists every command, q quits.
  4. 4
    Ask a first question. Type this at the prompt, with the dot at the end. Tau answers T: yes, x = 0 can be true. 
    sat x = 0.

The REPL runs only on your computer: no wallet, no server, no testnet.
