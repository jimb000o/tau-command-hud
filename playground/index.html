    Rules that bind everyone, like the base fee, change only when enough validators agree. Here you hold one of four seats. Pick a change or write your own, then vote.

    The real testnet today: one validator (a1fe40…7d2b, most likely run by IDNI), so the quorum is 1. The network also runs with open governance admission: a proposal or a vote from any key counts, so a single yes vote schedules a change. Here the seat is simulated and only validators vote, which is the code’s default. Counting, quorum and the delay before a change takes effect work as on the real node.
