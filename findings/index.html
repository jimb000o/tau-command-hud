      Found a bug in the testnet?

      IDNI runs a bug bounty for the Tau testnet. Real, reproducible bugs go to them as a GitHub issue; one issue per bug.

      Report it to IDNI Search known issues first

      A good report has

      1. What you did, step by step, so someone else can repeat it.
      2. What happened and what you expected instead.
      3. Where: node commit, network (tau-testnet-v2), block height, tx hash.
      4. Proof: the log lines or RPC replies that show it.

      Something wrong with Tau HUD?

      A wrong number, a broken page, an idea: that is ours, not IDNI’s.
