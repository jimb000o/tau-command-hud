Before you start

          
Is it safe for my server?
It opens only SSH and the peer port 4001. The node’s own interfaces stay inside Docker; nothing on the server is shared.

          
Does it need looking after?
No. It restarts by itself and resyncs when the testnet restarts. To update, run the same command again.

          
What does tauhud.com learn?
The name, height, latest block hash and kit version, once a minute. No address, no keys. Leave the name empty and nothing is sent.

          
How do I stop?
cd /opt/tau-node-kit/kit && docker compose down
