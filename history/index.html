How the history is rebuilt: the page replays every block in order, exactly as the node’s governance code does (governance.py ↗): a proposal waits for votes, becomes agreed once it holds the quorum, and takes effect at its activation block. If it is still short of votes by then, it is dropped and the old rules stay. At the newest block the result is checked against the node’s own state.
