Why this is not a normal blockchain

Its users write the rules in logic. Every rule is checked before it applies. The rules change only when the validators agree. There is no admin key.

About this page

      
Unofficial community projectBuilt by Tau community members. Not affiliated with, endorsed by or maintained by IDNI or the Tau team. Data in simulation mode is generated in your browser and is not the real chain.

      
Simulation vs. live node

      
The simulation follows the documented protocol of tau-testnet: validators vote on rule changes, accounts write and share their own Tau rules, every block is judged by Tau. It is a model, not the real chain.

      
Live mode speaks the node's raw WebSocket protocol (getblocks, getmempool, getgovernance). The public testnet bootnode only exposes P2P, so run your own read node (Docker, see the README), allow this page's origin with TAU_WS_ALLOWED_ORIGINS, then switch to Live node.
